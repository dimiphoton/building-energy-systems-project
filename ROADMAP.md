# Roadmap

Étude de chauffage d'un immeuble à Danderyd (cours ETA013). La variante
est fixée par la date du 29 août 1986. Le tout a été livré d'un bloc,
parce que le sujet est un seul calcul.

- [x] Cadrage — métier BI, domaine bâtiment, stack Python / pandas / matplotlib
- [x] Enveloppe — U du mur (méthode λ), Um, ponts thermiques des coursives
- [x] Ventilation CO₂, constante de temps, DVUT, puissance de dimensionnement
- [x] Saison de chauffe, diagramme de durée, correction d'année normale
- [x] Nombre d'énergie primaire, classe, et trois scénarios de travaux
- [x] Rapport, graphes, README et quatre présentations
